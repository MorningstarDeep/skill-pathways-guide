## 🔧 How to Set Their Passwords

### Method 1: Set Password via AWS Console (Recommended)

1. **Go to IAM Users**

   - Open: https://console.aws.amazon.com/iam/
   - Click **"Users"** in left sidebar

2. **Set Password for Krishna Jalan**

   - Click on `krishna-jalan`
   - Click **"Security credentials"** tab
   - Under **"Console sign-in"**, click **"Enable console access"** or **"Manage"**
   - Select **"Custom password"**
   - Enter a strong password (e.g., `TempPass123!Krishna`)
   - ✅ Check **"User must create a new password at next sign-in"** (recommended)
   - Click **"Apply"**

3. **Repeat for Hathim Mohammed**
   - Go back to Users → Click `hathim-mohammed`
   - Follow same steps with a different password (e.g., `TempPass123!Hathim`)

### Method 2: Generate Random Passwords (More Secure)

If you want AWS to generate secure passwords:

1. In the "Console password" section, select **"Autogenerated password"**
2. Click **"Apply"**
3. **IMPORTANT**: Click **"Download .csv"** to save the password
4. Share this password securely with your teammate

## 🆘 Troubleshooting

### "Invalid username or password"

- Make sure they're using the correct sign-in URL: https://703581221884.signin.aws.amazon.com/console
- Username is case-sensitive: `krishna-jalan` (all lowercase)
- Confirm you set the password in AWS Console

### "User must change password"

- This is normal! Click "Change password"
- Enter old password (the one you gave them)
- Enter new password twice
- Click "Confirm"

### "MFA required" (if you enable it)

- They need to set up MFA first
- Go to IAM → Users → Security credentials → MFA
- Follow the setup wizard with Google Authenticator or Authy app

### Need to Reset Password?

1. Go to IAM → Users → Click username
2. Security credentials tab
3. Click "Manage" next to Console password
4. Generate new password
5. Share securely with teammate
